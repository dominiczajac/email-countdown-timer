# Privacy

The canonical [privacy and data-handling disclosure](https://github.com/dominiczajac/email-countdown-timer/blob/main/docs/PRIVACY.md) describes owned settings/cache, retention, request processing and verification boundaries.

The plugin implements no visitor analytics, email-open tracking, telemetry, visitor cookies, persistent browser storage or automatic Google connections. This does not mean the hosting server, WordPress, CDN or email-image proxy processes no personal data. Review their request logging and retention separately. Do not enter private or per-recipient data into public timer IDs, labels, URLs or alternative text.

[Data Removal](Data-Removal.md) documents opt-in uninstall. [Fonts](Fonts.md) distinguishes current manual installation from the proposed automatic importer.
