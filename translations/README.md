# Tickloom Countdown Timers 12.9.2 translation drafts

These PO files target the WordPress.org release built from commit `f026fdce80d9f2aaa4e3b981738f771eb66804e4`. Each of the ten new files covers 359 plugin interface and block metadata strings found in that release. The Polish file preserves the earlier 68-entry draft.

The new drafts are machine translations of public plugin strings with checks for missing entries and formatting placeholders. Review wording and terminology with native speakers. The WordPress.org readme has its own translation project.

Download the desired PO file using GitHub's **Download raw file** action. For official language packs, use the matching locale in the [Stable translation project](https://translate.wordpress.org/projects/wp-plugins/tickloom-countdown-timers/stable/) and submit the translations for review. WordPress.org generates the language packs from approved translations.

The locales were chosen using [WordPress locale usage statistics](https://api.wordpress.org/stats/locale/1.0/), leaving out English and the previously prepared Polish locale.
